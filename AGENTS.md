# NFSU2 RE recovery rules

Recover original UG2 code and mechanics first. Other games only fill features or
assets absent from UG2. Never add custom-game policies, map offsets, wheel/FFB,
optional handling, progression changes or platform adapters to original routines.
Preserve evidence, call boundaries and arithmetic order. Keep unknown field names
offset-based until identified. Mark behavioral verification separately from byte
matching. Do not invent algorithms or force registers to fake a match.

Keep retail inputs and generated disassembly local under ignored directories.
Compile MSVC/wibo verification jobs sequentially. Application development belongs in separate repositories. Do not copy custom OpenUG2 gameplay into original sources.
